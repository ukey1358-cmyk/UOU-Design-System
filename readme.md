## CONTENT FUNDAMENTALS (카피 작성 원칙)

대학 공식 커뮤니케이션 톤. 차분하고 신뢰감 있게, 격식을 지키되 건조하지 않게.

- **언어/높임**: 한국어 우선, 격식체. 본문은 **'~합니다 / ~하세요'** 의 정중한 평·청유체.
  명령형 대신 안내형("확인하세요", "신청하세요").
- **인칭**: 1인칭 '저희/우리 대학', 독자는 '여러분' 또는 무인칭. 과도한 '당신' 회피.
- **국·영문 병기**: 교명·기관명은 한글 + 영문 병기 가능 (`울산대학교 / UNIVERSITY OF ULSAN`).
  영문은 **대문자 + 넓은 자간**으로 상징성 부여.
- **숫자·날짜**: 연도 4자리, 날짜는 `2026.06.12` 형식(점 구분, 모노스페이스 권장).
  학년도 표기 `2026학년도 1학기`.
- **라벨/배지**: 짧은 명사형 분류 — `학사`, `장학`, `채용`, `행사`, 신규는 `N`.
- **제목**: 핵심을 앞세운 명사구. "2026학년도 1학기 수강신청 일정 안내" 처럼 대상→내용→유형.
- **이모지 사용 안 함.** 공식 대학 커뮤니케이션에는 이모지를 쓰지 않습니다. 강조는 색/배지로.
- **슬로건 톤**: 교훈 "진리 · 자주 · 봉사", "미래를 여는 대학" 처럼 간결·진취적.
- **금지**: 과장된 마케팅 문구, 느낌표 남발, 구어체 줄임말.

예시
- 헤드라인: "미래를 여는 대학, 울산대학교"
- 리드: "탁월한 인재 양성을 위한 교육과 연구. 신뢰받는 지역 거점 대학으로서 세계와 함께 성장합니다."
- 안내: "2학기 국가장학금 신청 안내 (1차)"

## VISUAL FOUNDATIONS (시각 기반)

**전체 인상**: 화이트 캔버스에 그린 포인트. 넓은 여백, 얇은 보더, 절제된 그림자.
학구적이고 단정한 관공서/대학 톤 — 장식·질감·그라데이션을 과하게 쓰지 않습니다.

- **색 (Color)**: 주색 **UOU Green `#009A44`** 는 **액션·링크·강조에만** 사용. 넓은 면적은
  화이트(`--gray-0`)와 라이트 그레이(`--gray-50`)로 비웁니다. 본문 텍스트는 **UOU Gray
  `#333333`**(`--gray-800`), 제목은 `--gray-900`. **옐로우 `#CC9900`** 는 배지·하이라이트 등
  좁은 영역에만 절제 사용. 마스코트는 **별도 파스텔 그린 팔레트**(`--ulrinee-*`)를 쓰며 코퍼레이트
  그린과 혼용하지 않습니다.
- **타입 (Type)**: `--font-sans` = **Pretendard** (브랜드 전용서체 우리고딕의 웹 대체 —
  장식 배제, 단순·명쾌·현대적). 굵기는 400/500/700 3단계. 스케일 display 48 → caption 12.
  제목은 700, 카드 제목(h4)은 500. `text-wrap: balance/pretty` 사용.
- **배경 (Background)**: 기본 솔리드 화이트. 섹션 구분은 `--gray-50`. **히어로**에 한해 그린
  딥 그라데이션(`green-800 → green-700`)과 반투명 'Σ' 워터마크를 1회 사용 — 그 외 그라데이션은 지양.
  반복 패턴·텍스처·사진 풀블리드는 기본 사용 안 함(이미지 제공 시 추가).
- **모서리 (Radius)**: 배지/입력 4px, 버튼/소형 카드 8px, 카드/모달 12px, 큰 컨테이너 16px,
  칩/아바타 full. 일관되게 토큰 사용.
- **카드 (Card)**: 흰 배경 + `1px var(--gray-200)` 보더 **또는** `--shadow-sm`. radius 12px,
  패딩 24px. **클릭형**은 hover 시 `--shadow-md` + **상단 3px 그린 보더**.
- **그림자 (Shadow)**: 3단계만. sm `0 1px 2px /.06`, md `0 2px 8px /.08`, lg `0 8px 24px /.12`.
  은은하게, 컬러 섀도우 없음.
- **보더 (Border)**: 기본 `--gray-200`, 입력 `--gray-300`, 강조선은 그린. 헤더/탭 하단 1px 구분선.
- **애니메이션 (Animation)**: 절제. `120–140ms ease` 의 색/그림자/보더 트랜지션 정도.
  바운스·무한 루프·화려한 모션 없음. hover는 **색 변화**(그린 → 진한 그린, 또는 그린 틴트 배경).
- **상태 (States)**: hover = 색 진하게/틴트 배경 + (텍스트 버튼) 밑줄. focus = 그린 보더 +
  포커스 링 `0 0 0 3px rgba(0,154,68,0.15)`. disabled = opacity 0.45 또는 gray-100 배경.
  press 시 별도 축소 없음(색만 더 진하게).
- **투명/블러**: 거의 사용 안 함. 히어로 워터마크의 5% 화이트 정도만.
- **레이아웃**: 콘텐츠 최대 폭 `--container-max: 1200px`, 좌우 24px 거터. GNB는 sticky.
  4px 기준 간격 스케일. 충분한 여백으로 학구적 인상 유지.
- **로고 보호**: 심볼·시그니처 주변 넉넉한 여백. **변형 금지**(늘리기/압축/회전/색변경).

## ICONOGRAPHY (아이콘)

- 공식 CI 매뉴얼에는 **전용 아이콘 세트가 규정되어 있지 않습니다.** 픽토그램은 단순·명쾌한
  라인 스타일을 권장하는 톤만 존재합니다.
- ⚠️ **SUBSTITUTION**: 본 시스템은 **[Lucide](https://lucide.dev)** (얇은 라인, stroke ~1.75)를
  CDN으로 사용합니다. UI 키트에서 `<i data-lucide="...">` + `lucide.createIcons()` 패턴으로 로드.
  공식 아이콘 세트가 제공되면 교체하세요.
- **색**: 아이콘은 기본 `currentColor`. 강조 아이콘은 `--green-600`.
- **이모지**: 공식 커뮤니케이션에 **사용하지 않습니다.**
- 자주 쓰는 아이콘: `search`, `menu`, `calendar-days`, `graduation-cap`, `book-open`,
  `building-2`, `briefcase`, `users`, `chevron-right`, 소셜(`instagram`/`youtube`/`facebook`).

## 사용 원칙 (Usage Principles)

1. **그린은 강조에만.** 넓은 면적은 화이트/그레이로 비웁니다.
2. **옐로우는 절제.** 배지·하이라이트 등 좁은 영역에만.
3. **본문은 UOU Gray** `#333333`, 제목은 `#1C1E20`.
4. **충분한 여백.** 심볼·시그니처 주변과 블록 사이 넉넉히.
5. **로고 변형 금지.** 형태·굵기·비례·색상 임의 변경 불가.
6. **대비 확보.** 그린 배경 위 텍스트는 흰색, 옐로우 배경 위 텍스트는 `#A67A00` 이상 진한 색.
