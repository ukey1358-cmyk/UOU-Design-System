## ⚠️ 아직 필요한 공식 에셋 (선택)

원본 벡터(`.ai`/`.svg`)가 필요하면 추가로 올려주세요. 현재 래스터 PNG(추출본)로 충분히
화면 사용 가능하나, 대형 인쇄·사인물에는 벡터 원본이 권장됩니다. 또한 `signature-sheet.png`
는 4종이 한 시트에 합쳐져 있어, 특정 변형(예: 흑백 가로형)만 단독으로 필요하면 알려주세요 —
잘라서 개별 파일로 분리해 드립니다.
