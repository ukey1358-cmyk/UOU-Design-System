# UOU 인사행정 챗봇 — UI 재설계 적용 안내

`gr.Blocks` 기반으로 사이드바 + 상단바 레이아웃을 새로 구성하고, UOU 브랜드(녹색 #009A44 · Pretendard · 로고)를 입힌 버전입니다. **검색·Gemini 백엔드 로직은 기존과 100% 동일**하며 UI만 교체됩니다.

## 적용 방법 (3단계)

1. **app.py 교체**
   - 이 폴더의 `app.py` 를 챗봇 프로젝트의 `src/app.py` 에 덮어쓰기.

2. **로고 추가**
   - 이 폴더의 `assets/logomark-solid.png` 를 `src/assets/logomark-solid.png` 로 복사.
   - (즉 `src/` 아래에 `assets` 폴더를 만들고 그 안에 로고를 넣습니다.)

3. **실행** — 기존과 동일
   ```powershell
   .\.venv\Scripts\python.exe app.py
   ```

## 바뀐 점
- 좌측 **사이드바**: 브랜드 로고, "새 대화" 버튼, 최근 대화 목록, 규정 49건 상태 표시
- 상단 **툴바**: 제목 + 대상자 필터 드롭다운(우측)
- **대화**: 녹색 사용자 말풍선 / 흰색 봇 말풍선 + 로고 아바타, 마크다운 출처·원문 링크
- **입력부**: 예시 질문 칩 + 둥근 입력창 + 녹색 전송 버튼
- 첫 화면에 환영 메시지 표시

## 참고 / 한계
- Gradio는 자체 DOM 구조를 생성하므로 목업과 **픽셀 단위로 100% 동일하지는 않습니다.** (특히 드롭다운·아바타 모서리 등 일부 컴포넌트 내부 스타일)
- "최근 대화" 목록은 현재 **정적 표시**입니다(클릭 시 불러오기는 미구현). 실제 대화 저장/불러오기가 필요하면 별도 작업이 필요합니다.
- 실행 후 미세하게 어긋나는 부분이 있으면 스크린샷을 주세요 — CSS를 한 번 더 맞추겠습니다.
- Pretendard 폰트는 CDN(jsdelivr)에서 로드합니다. 오프라인/폐쇄망 배포 시 폰트를 로컬에 포함해야 합니다.
